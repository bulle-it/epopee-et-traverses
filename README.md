# L'Epopee et ses traverses

Page d'explication factuelle : trois voies tentees depuis janvier 2026, les regles
officielles qui les barrent, et l'historique complet des demarches.

Toutes les affirmations sont sourcees (France-Visas, code communautaire des visas,
accord franco-algerien de 1968, arrete algerien du 9 janvier 2022, CESEDA,
statistiques consulaires). Les captures France-Visas datent du 20 septembre 2026.

Aucun nom, aucun numero de dossier, aucune piece nominative : les documents
justificatifs sont conserves separement, en acces restreint.
